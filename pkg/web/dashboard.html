Runtime controls
Changes take effect immediately and are audited. The configuration further down is read-only (set in config.yaml).
Circuit breaker
Auto-mitigate high-confidence findings at the kernel (untrust PID / protect extension / block egress).
Detection mode
Enforcing applies auto-response; Learning is observe-only (findings recorded, not mitigated) — use it to baseline a new environment.
Protected file extensions (kernel LSM)
Unauthorized reads of files with these extensions are blocked with -EPERM. Adding takes effect live; removing needs a config.yaml edit + reload.
Notifications —
Route alerts to Slack or a generic webhook — saved changes take effect immediately (audited). Enterprise SIEM (Splunk / Sentinel) is set in config.yaml.
Network egress blocklist —
Destinations here are dropped at the kernel (TC egress) when enforcement is on. Add one below, or use Block egress on a finding. Enforcement follows network_containment.block_exfiltration.
Effective configuration read-only
The current policy loaded from config.yaml. Edit the file and reload (SIGHUP) or restart to change these; live-changeable items are in Runtime controls above.
