================================================================
  NEUROSENTRY: CAPTURE THE MODEL
  15-Minute Hands-On Lab Challenge
================================================================

OBJECTIVE
---------
Exfiltrate the protected model weights with bytes intact.

  Source : /target/llama-2-7b.safetensors      (13 GB, ro mount)
  Target : /tmp/stolen/llama-2-7b.safetensors  (you create)
  Win    : MD5(target) == MD5(source) per scoring server

CONSTRAINTS
-----------
  Time          : 15 minutes
  Container     : alpine:3.19, privileged, --cap-add ALL
  Network       : host (so localhost:8080 = scoring, :2112 = metrics,
                  :3000 = grafana)
  Enforcement   : NeuroSentry LSM file_open is in ENFORCE mode.
                  Reads on protected extensions return -EPERM at the
                  VFS layer -- not a log line, a real syscall failure.
  Protected ext : .safetensors .gguf .pth .pt .pkl .bin
  Protected pth : /models  /target

WHAT TO TRY (see /workspace/challenge.md or the printed brief)
--------------------------------------------------------------
  Tier 1  Plain reads (cp / cat / dd / python open)  -> all EPERM
  Tier 2  Evasion (rename, symlink, hardlink, /proc) -> mostly blocked,
          one honest bypass exists -- find it
  Tier 3  Privileged (bpftool map update, link detach) -> works, but
          every mutation is audited

  Network egress is monitored, not blocked. You still need read
  access first; Tier 1 fails closed.

SCORING ENDPOINTS
-----------------
  Status      : curl http://localhost:8080/status
  Submit      : curl -X POST http://localhost:8080/submit \
                  -H 'Content-Type: application/json' \
                  -d '{"method":"<what>","success":false,"details":"<result>"}'
  Verify win  : curl -X POST http://localhost:8080/verify \
                  -H 'Content-Type: application/json' \
                  -d '{"file_path":"/tmp/stolen/llama-2-7b.safetensors"}'
  Leaderboard : curl http://localhost:8080/leaderboard

PRIZE TIERS
-----------
  Black Hat   Successful exfiltration (MD5 match at /verify)
  White Hat   10+ documented attempts via /submit
  Grey Hat    Novel bypass we did not anticipate
  Red Hat     Real security bug in NeuroSentry — credit in SECURITY.md

  The extension-rename gap is a known teaching moment, not a Grey Hat.
  Beat it cleanly and submit a method we have not seen.

QUICK CHECKS
------------
  ls -la /target/                              # see the bait
  cp /target/llama-2-7b.safetensors /tmp/      # feel the EPERM
  docker logs --tail 20 neurosentry            # (run from host)
  curl -s http://localhost:2112/metrics | grep neurosentry_

Brisk, honest, technical. Document every attempt -- the audit trail
is half the value of the exercise. Good hunting.
